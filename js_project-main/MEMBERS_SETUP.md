# 학급 입장과 관리자 멤버 목록

로그인한 계정으로 학급에 입장하면 Supabase에 이름과 입장 시각을 저장합니다. 관리자(해당 학급을 생성한 계정)는 멤버 탭에서 자신이 생성한 학급의 사용자를 확인할 수 있습니다. 다른 스마트폰·브라우저에서도 같은 데이터베이스를 사용합니다.

## 최초 연결

1. Supabase 프로젝트의 공개 anon/publishable 키를 `.env`의 `VITE_SUPABASE_ANON_KEY`에 설정합니다. URL과 키가 같은 프로젝트의 것이어야 합니다. secret/service_role 키는 넣지 않습니다. 키를 변경했다면 개발 서버를 다시 실행합니다.
2. Supabase SQL Editor에서 [마이그레이션](supabase/migrations/202610150001_classroom_members.sql)을 실행합니다. 새 학급·멤버 테이블과 인증된 계정의 학급 입장 함수를 만듭니다. 기존 테이블이나 계정은 삭제하지 않습니다.
3. 기존 학급을 만든 계정으로 기존 브라우저의 메인 화면을 엽니다. 브라우저에 임시저장되어 있던 학급을 코드 그대로 Supabase로 옮깁니다. 로컬 원본은 지우지 않습니다.
4. [내 클래스 조회 마이그레이션](supabase/migrations/202610150002_joined_classrooms.sql)을 실행합니다. 로그인 계정이 입장한 학급의 이름·학교·코드만 조회하는 함수를 추가합니다.
5. [학급 관리 마이그레이션](supabase/migrations/202610150003_classroom_management.sql)을 실행합니다. 계정당 학급 생성·입장을 제한하고, 해당 학급 선생님의 삭제·이름 수정 함수를 추가합니다. 기존에 생성과 입장을 모두 했던 계정의 기록은 자동 삭제하지 않습니다.
6. [학급 탈퇴 마이그레이션](supabase/migrations/202610150004_leave_classroom.sql)을 실행합니다. 학생이 본인의 입장 기록만 삭제할 수 있는 함수를 추가합니다.

인증 설정 API의 200 응답만으로는 DB 연결 키가 유효하다고 볼 수 없습니다. 실제 학급 조회 또는 Data API 요청이 성공해야 연결이 확인됩니다.

## 사용

- 일반 사용자: 로그인 → 학급 입장 → 성함·학급코드 입력 → 입장.
- 입장하면 `내 클래스` 탭에 해당 학급이 바로 표시됩니다. 새로고침하거나 다른 기기에서 로그인해도 DB의 입장 기록을 불러옵니다. 직접 생성한 학급은 `관리 중인 클래스`에 표시합니다.
- 관리자: 멤버 탭에서 관리하는 학급의 사용자 목록을 바로 확인합니다. 탭을 누르거나 새로고침하면 최신 목록이 표시됩니다.
- 생성하거나 입장한 학급이 있으면 새 학급 생성 버튼은 표시하지 않습니다.
- 학급을 생성한 계정은 선생님, 코드로 입장한 계정은 학생입니다. 이미 생성하거나 입장한 학급이 있으면 `학급이 있으면 안됩니다` 오류로 추가 입장과 생성을 막습니다. 동시 요청도 DB에서 같은 계정의 잠금으로 직렬 처리합니다.
- 선생님은 학급 카드에서 학급을 삭제하거나 멤버 목록에서 학생을 제외하고 이름을 수정할 수 있습니다. 삭제 전에는 확인창이 뜹니다. 학생 계정 자체나 로그인 이름은 변경하지 않습니다.
- 학급 삭제는 `deleted_at`으로 비활성화합니다. 학생들의 내 클래스에서 사라지고 코드를 통한 입장이 막힙니다. 삭제한 ID는 예전 로컬 백업의 재등록을 방지하기 위해 남깁니다. 학생 제외는 해당 학급의 멤버 기록만 삭제합니다.
- 학생은 내 클래스 카드의 `학급 탈퇴`를 눌러 확인 후 탈퇴할 수 있습니다. 다른 학생이나 학급, 계정은 삭제하지 않습니다. 탈퇴 후 다른 학급 입장이나 새 학급 생성이 가능합니다. 본인이 생성한 학급에는 탈퇴 대신 학급 삭제 버튼을 표시합니다.
- 다른 학급 코드나 비로그인 요청은 입장을 완료 처리하지 않습니다.

## 접근 권한

- 학급은 생성한 계정만 조회·생성할 수 있습니다.
- 멤버는 본인 기록 또는 자신이 관리하는 학급의 기록만 조회할 수 있습니다.
- 멤버 테이블에 브라우저가 직접 쓰지 못하며, 로그인 계정과 학급코드를 확인하는 `join_checkin_classroom` 함수를 통해서만 등록합니다.
- 함수의 사용자 ID는 `auth.uid()`에서 가져옵니다. 폼에 사용자 ID나 관리자 ID를 넣어 권한을 바꿀 수 없습니다.

참고: [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security).
